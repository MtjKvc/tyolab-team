O projekte

Webová platforma TYOLab umožní používateľom vytvárať a využívať modely umelej inteligencie bez potreby hlbokých znalostí strojového učenia alebo programovania.

Cieľom projektu je navrhnúť a implementovať platformu TYOLab ako univerzálne prostredie pre prácu s používateľskými dátami, ich analýzu, prípravu pre strojové učenie, automatizované trénovanie modelov a ich následné využitie pri riešení praktických problémov. Platforma prevedie používateľa celým procesom od nahratia vlastných dát až po nasadenie natrénovaného modelu.

      Priebeh stretnutia

      • Kontrola úloh z predchádzajúceho stretnutia.
      • Diskusia o backendovej časti platformy:
        • Backend: Python a FastAPI.
        • Využívanie virtuálneho prostredia (venv) pre izoláciu Python závislostí.
        • Roly v systéme — admin, firma (správca firmy), user. Admin vidí všetko, firma vidí všetko v rámci svojej skupiny, user vidí len svoje vlastné datasety a modely. Skupiny/firmy sa navzájom nevidia.
        • Spôsob autorizácie a obmedzenia viditeľnosti dát v API.
        • Ukladanie súborov pre datasety — štruktúra priečinkov, väzba súborov na dataset, podpora viacerých CSV súborov v rámci jedného datasetu.
        • Predspracovanie dát pre frontend — endpointy pre EDA: štatistiky, typy stĺpcov (kategorický/číselný), početnosti, rozptyl a ďalšie základné údaje nad každým stĺpcom.
        • Návrh REST API pre komunikáciu frontendu s backendom.
      • Návrh dátového modelu pre používateľov, roly a datasety.
